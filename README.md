# مراقب أسعار مكعب (Mokab Price Tracker)

مشروع **منفصل تماماً** عن مشروع تحليل مراجعات فروع مكعب على Google Maps (ذاك في مستودع `Mokab_review`). هذا المستودع غرضه الوحيد: مراقبة أسعار ومنتجات محددة على موقع **mokab.com** والتنبيه عند أي تغيير.

## الهدف

4. **براند DDPAI** — `https://mokab.com/ar/ddpai/brand-1171611633`
5. **منتجات التنقل — NAVEE** — `https://mokab.com/ar/navee/brand-2096663475`
6. **منتجات التنقل — Airwheel** — `https://mokab.com/ar/airwheel/brand-1293951655`

## البنية التقنية (لماذا هذا التصميم بالذات)

- **لا يوجد Apify ولا مهمة Claude مجدولة** — جرّبنا ذلك أولاً لكنه يكلّف (Apify compute units) ويعتمد على فتح تطبيق Claude. استبدلناه بالكامل بـ **GitHub Actions** لأنه مجاني ومستقل عن أي جهاز/تطبيق.
- **لا حاجة لمتصفح آلي (Playwright) في الغالب** — اكتشفنا أن مكعب يضمّن بيانات كل منتج (الاسم، السعر، حالة التوفر) كـ JSON-LD (schema.org) في HTML الخام لأغراض SEO، فطلب HTTP عادي بمكتبة `requests` يكفي. الكود يحاول Playwright فقط كخطة بديلة إذا فشل الطلب العادي.
- **التنبيه عبر GitHub Issues** — عند اكتشاف أي تغيير، يُفتح Issue في هذا المستودع، وGitHub يرسل بريد تلقائي (بدون أي إعداد SMTP أو أسرار إضافية). **لا يوجد تيليجرام حالياً** (تم استبعاده بطلب المستخدم).

## الملفات

| الملف | الوظيفة |
|---|---|
| `check_prices.py` | السكربت الرئيسي: يتصفح كل صفحات الترقيم (pagination) لكل مصدر، يستخرج JSON-LD، يقارن بخط الأساس، يبني تقرير التغييرات |
| `mokab_price_baseline.json` | "الذاكرة" — آخر حالة معروفة لكل منتج (السعر، السعر الأصلي، حالة التوفر، الأقسام). يتحدّث تلقائياً بعد كل تشغيل |
| `.github/workflows/price-check.yml` | يشغّل السكربت يومياً 6:00 صباحاً بتوقيت السعودية (`0 3 * * *` UTC)، ويفتح Issue إذا لزم |

## أنواع التنبيهات المفعّلة حالياً

1. 💰 **تغيّر السعر الحالي** (بيع)
2. 🏷️ **تغيّر نسبة الخصم/العرض** (السعر الأصلي قبل الخصم تغيّر حتى لو السعر النهائي ثابت)
3. 📦 **تغيّر حالة التوفر** (متوفر ↔ نفد)
4. 🆕 **منتج جديد** ظهر لأول مرة في أحد الأقسام الستة
5. ❌ **منتج اختفى** تماماً من كل الأقسام (غالباً نفاد مخزون أو إيقاف)

كل هذه تُجمع في Issue واحد يومي مقسّم لأقسام واضحة، وليس عدة تنبيهات متفرقة.

## كيف تُشغّله يدوياً للتأكد

تبويب **Actions** في المستودع ← **Mokab Price Check** ← زر **Run workflow**.

## إذا احتجت لاحقاً (أفكار جاهزة لم تُفعّل بعد)

- ربط بتيليجرام (بوت + chat_id كـ GitHub Secrets) بدل/بجانب GitHub Issues
- إضافة فئات/براندات جديدة (فقط أضف رابط جديد في قائمة `SOURCES` داخل `check_prices.py`)
- تتبّع تقييمات المنتجات (aggregateRating) كمؤشر تسويقي إضافي
- رسم بياني لتاريخ السعر عبر الزمن (يحتاج تخزين تاريخي وليس فقط آخر قيمة)
- توسيع المراقبة لتشمل منافسين آخرين غير مكعب (Amazon استُبعد صراحة من هذا المشروع بطلب المستخدم)

## قواعد التعامل مع هذا المشروع

- هذا المشروع **لا علاقة له** بمشروع تحليل مراجعات فروع مكعب (مستودع `Mokab_review`، الداشبوردات، تحليل الموظفين، إلخ) — لا تخلط بينهما.
- أي طلب مستقبلي بخصوص "أسعار مكعب" أو "مراقبة المنافس" أو تعديل على `SOURCES`/التنبيهات يخص هذا المستودع (`mokab-price-tracker`) حصراً.
- عند إضافة نوع تنبيه جديد أو مصدر جديد، حدّث هذا الملف (README) ليبقى مرجعاً كاملاً ومحدّثاً.
